# Active Learning for cholec80

This module adds **pool-based active learning** to the EndoNet pipeline,
enabling you to achieve good phase/tool recognition accuracy with
significantly fewer annotated frames than full supervision.

---

## What is Active Learning?

Instead of labeling the entire training set, the model iteratively:
1. Trains on a small labeled seed set.
2. Scores every unlabeled frame according to an *informativeness* criterion.
3. Asks the annotator to label only the **most informative** frames.
4. Repeats.

On typical surgical-video datasets, AL reduces annotation effort by
**40–60 %** while matching fully-supervised accuracy.

---

## Implemented Strategies

| ID | Strategy | Family | Description |
|----|----------|--------|-------------|
| `random` | Random | Baseline | Uniform random selection — no model inference needed |
| `least_confidence` | Least Confidence | Uncertainty | Frames with the lowest max-class probability |
| `margin` | Margin Sampling | Uncertainty | Frames with the smallest gap between the top-2 class probabilities |
| `entropy` | Entropy Sampling | Uncertainty | Frames with the highest predictive entropy |
| `mc_dropout` | BALD (MC Dropout) | Bayesian | BALD score from T stochastic forward passes with dropout enabled |
| `coreset` | Core-Set | Diversity | Greedy k-center: maximally covers the feature space |
| `badge` | BADGE | Hybrid | k-means++ on gradient embeddings — diverse *and* uncertain |

**Recommended starting point:** `entropy` (fast, strong baseline) or
`badge` (best reported results in the BADGE paper).

## Quick Start

### Prerequisites

Install the same dependencies as EndoNet, plus `scipy` and `scikit-learn`:

```bash
pip install scipy scikit-learn
```

### Prepare the CSV files

The CSVs must already be generated by `EndoNet/data/make_train_test.py`.
They should have the columns:

```
video_name, Frame, file_loc,
Preparation, CalotTriangleDissection, ClippingCutting,
GallbladderDissection, GallbladderPackaging,
CleaningCoagulation, GallbladderRetraction,
Grasper, Bipolar, Hook, Scissors, Clipper, Irrigator, SpecimenBag
```

### Run active learning

```bash
cd active_learning

# Entropy sampling — 10 rounds, 200 frames queried per round
python active_train.py \
    --train_csv /path/to/EndoNet/train_set_info.csv \
    --test_csv  /path/to/EndoNet/test_set_info.csv  \
    --strategy  entropy \
    --n_rounds  10 \
    --query_budget 200 \
    --initial_ratio 0.05 \
    --epochs_per_round 20 \
    --output_dir ./results

# MC Dropout (BALD)
python active_train.py \
    --train_csv ... --test_csv ... \
    --strategy mc_dropout \
    --output_dir ./results

# Core-Set
python active_train.py \
    --train_csv ... --test_csv ... \
    --strategy coreset \
    --output_dir ./results

# BADGE
python active_train.py \
    --train_csv ... --test_csv ... \
    --strategy badge \
    --output_dir ./results
```

Each run writes:
- `results/al_<strategy>.json` — per-round metrics (loss, phase acc, phase F1, tool acc)
- `results/model_<strategy>_final.pth` — final model checkpoint

## Comparing Strategies

Run all strategies in sequence and compare the JSON files:

```bash
for strategy in random least_confidence margin entropy mc_dropout coreset badge; do
    python active_train.py \
        --train_csv /path/to/train_set_info.csv \
        --test_csv  /path/to/test_set_info.csv  \
        --strategy  $strategy \
        --n_rounds  10 --query_budget 200 \
        --output_dir ./results
done
```

Then load the JSON files in a notebook:

```python
import json, glob, pandas as pd, matplotlib.pyplot as plt

dfs = []
for path in glob.glob('results/al_*.json'):
    data = json.load(open(path))
    df = pd.DataFrame(data['rounds'])
    df['strategy'] = data['strategy']
    dfs.append(df)

results = pd.concat(dfs)

for strategy, g in results.groupby('strategy'):
    plt.plot(g['n_labeled'], g['test_phase_acc'], marker='o', label=strategy)

plt.xlabel('# labeled frames')
plt.ylabel('Test phase accuracy')
plt.legend()
plt.title('Active Learning — cholec80 phase recognition')
plt.tight_layout()
plt.savefig('al_comparison.png', dpi=150)
plt.show()
```

## Key Parameters

| Parameter | Default | Meaning |
|-----------|---------|---------|
| `--initial_ratio` | 0.05 | Fraction of training frames labeled at round 0 (≈ 5 %) |
| `--n_rounds` | 10 | Total AL cycles |
| `--query_budget` | 200 | Frames added per round |
| `--epochs_per_round` | 20 | Training epochs per cycle |
| `--batch_size` | 16 | Mini-batch size |
| `--seed` | 42 | RNG seed for reproducible pool initialisation |

Edit `al_config.py` to change MC Dropout passes (`mc_dropout_passes`) or
BADGE PCA dimension (`badge_pca_dim`).

## Design Notes

- **Pool management** (`CholecPoolDataset`): maintains a boolean labeled
  mask over the full training CSV.  `label_samples()` takes indices into
  the *current* unlabeled array, preventing double-counting.
- **CoreSet** requires the labeled feature set to initialise distances.
  The script automatically passes `labeled_loader` to `strategy.query()`.
- **BADGE** applies PCA (default 256 components) before k-means++ to keep
  memory manageable for large pools (raw gradient embedding = 28 721-dim).
- The model is **retrained from scratch** every round to avoid confirmation
  bias from a warm-started model (standard practice in the AL literature).
